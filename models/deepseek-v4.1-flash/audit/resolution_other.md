## Exclusions and scope boundaries

Exclude throughput, timings, memory hardware capacities, expert cache counts, context capacity, speculative acceptance, parameter counts and pass counts for kernel/compatibility tests as quantization-quality metrics. YoungAi speech-recognition error figures concern Moonshine, not DeepSeek. No quality score is inferred for draft/vision files from their sizes or quantization labels. No derivative is treated as BF16 simply because a card uses a general “full precision” phrase. No lossless-conversion statement is converted into a synthetic zero KLD. Metadata about storage components is retained in flags rather than combined into an invented total.
