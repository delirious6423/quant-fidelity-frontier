# Resolver wave 1

Owned only the five repositories listed in `work/deepseek-v4.1-flash/resolve_1.json`. Compared both independent maps, read each complete pinned card, checked every source SHA-256, and wrote complete maps to `maps/resolved/`. No A/B or tracked verified file was edited.

## Decisions

- **satgeze EXL3 2.0bpw Ablit EngramQ4:** 9 entries, 37 metrics. A correctly distinguishes the published trajectory log-probability gap from distribution KL; B's `mean_kld` relabeling is rejected. The card defines its “KL” as the average sampled-token `log p_official(t*) - log p_arm(t*)` (L239–243), so it remains `bench:mean trajectory log-prob ratio`, never generic KLD or restricted-distribution KL. Trajectory PPL and top-1 keep explicitly named official-trajectory corpus keys. Each arm's bounded task battery is separate from trajectory scoring; the shipped abliterated rerun (3,957 positions, L254–256), nominal Mia trajectory protocol (40 contexts ×128 tokens), and earlier stock replay (165K tokens, L252–253) keep separate methods. The before/after table is a distinct exact-heading panel. Official API scores are author-measured `cross`, attributed to the named DeepSeek model with API checkpoint revision/precision explicitly unspecified, not a publisher-owned ladder build. The unnamed exact HF repository for the Mia arm is not invented. Stock/pre-graft and historical stock arms remain publisher comparison `ladder` builds. Preserve `weights_modified=true` for the graft and Engram recompression (L96–99). Full refusal/tool/short-loop count fractions are copied programmatically from their intended source cells. Retracted throughput results, smoke-test descriptions without numeric scores, speed/cache statistics, and hypothetical or derived KLD values are excluded. The source does not state complete pack size; no component size is attached as whole-model size.
- **PipeNetwork REAP25 mixed4/8:** 7 entries, 20 metrics. Preserve expert pruning and DSpark/MTP omission as modified weights (L25,63). Own perplexity and paired ratio retain their published intervals, corpus, 140 matched 2048-token windows, and unpruned quantized reference (L85). The reference's BF16 computation comes from dequantizing native FP8/FP4 source weights, not a natively BF16 checkpoint (L23–24,67). Retain the six explicit converter recipe studies omitted by B as `ladder` component measurements, with separate `component:teacher_forced_mean_divergence`, `component:free_running_final_layer_divergence`, and `component:final_layer_cosine` keys. Their hidden-state divergence definition is unspecified; none is relabeled as next-token KL. These recipes are not identified as the pruned REAP25 artifact, so own size 351.1 GB on disk is assigned only to the own perplexity entry; component-study rows receive no inferred size. Calibration saliency and runtime parity/negative-control figures are not treated as downstream quality scores.
- **AMD Quark MXFP4:** 4 entries, 6 metrics. Native source baseline is author-measured `cross` (`deepseek-ai/DeepSeek-V4.1-Flash`), correcting A's ladder role. Preserve A's separate GSM8K and GPQA methods under exact source heading `Accuracy`: GSM8K is 8-shot greedy with seed42 and 4096 generation tokens; GPQA is 198-question 0-shot thinking, temperature1/top_p0.95, one repeat, 65536 generation tokens. Own recovery percentages are retained as distinct labeled metrics from B, alongside raw task scores. The card explicitly says the stochastic GPQA gap is within its confidence interval (L100–105); no superiority inference is added. Quantization alone keeps `weights_modified=false`.
- **LibertAIDAI NVFP4:** 2 entries, 2 metrics. Each result is `component:engram_mean_cosine` over 1.5M sampled rows of one named output Engram table (L94–97), never top-1/logit agreement or a whole-model task benchmark. Each 48.8 GiB size has `basis: engram_only` and an explicit single-table flag. The card explicitly disclaims end-to-end evaluation (L99–103,181–197). Lossless expert reconstruction does not create a synthetic zero KLD. Quantization-only `weights_modified=false` remains.
- **lvkaokao W4A16 Engram AutoRound:** 2 entries, 1 metric. The own slash-separated GSM8K pair has no labels indicating score extraction, runs or variants (L20–21); follow the mapping rule for ambiguity and exclude both components from numeric task metrics rather than choose one or invent meanings. Keep the author-measured official baseline score, explicit native MXFP4/FP8 precision, raw five-shot/thinking-off protocol, and both source-stated checkpoint sizes (451.7 GB own, 510.3 GB official). The flag explains the excluded pair. No value is rounded or interpreted as a strict/flexible result. Quantization-only `weights_modified=false` remains.
